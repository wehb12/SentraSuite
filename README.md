# Sentra Suite
## Setup Guide

1. Clone this git repro somewhere
2. Download Projucer from https://juce.com/download/ (either build from source or use the binary version)
3. Run Projucer
4. Open a project in Projucer
5. Click on the WavetableSynth.jucer file to open in Projucer
6. Click the Save and Open In IDE button
7. Find a way to run the vst3 through the AudioPluginHost (may need to build this yourself if using projucer from code) or just build the raw vst3 and load it into a DAW to test
